# Latidos37 Radio

Crea una web moderna, artística y editorial para el programa de radio y podcast “LATIDOS37”.
El sitio debe tener una estética inspirada en el constructivismo soviético, el diseño funk/disco de los 70, cartelería musical underground y gráfica experimental contemporánea.
Debe sentirse como una mezcla entre un cartel cultural, una revista musical indie y una radio alternativa.
